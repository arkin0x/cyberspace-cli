## 2. Block anchor events (kind 321)

| Section | Rule | Status | Where |
|---|---|---|---|
| 2.1 | Read `C`, `M`, `B`, `H` | DONE | `cli._stop_from_anchor` |
| 2.2 | Anchor without `M`: `C` is the merkle root; plane-0 blocks derive the landfall from `H`; `C` is never a landfall position | DONE | `hyperspace.resolve_stop` |
| 2.3 | With `M`: `C` must equal the derivation from `M` and `H`, else the anchor is invalid | DONE (internal consistency). Block data itself is not verified against Bitcoin; `--source mempool` fetches the header from mempool.space and derives locally | `resolve_stop`, `cli._fetch_block_from_mempool` |
| 2.4 | Header blobs | TODO | |

Anchor preference when several exist for one height: v3 anchors (with `M`) first, then newest `created_at`. The 2024 legacy publisher (`811ccc1b...`) wrote `C` as the byte-reversed merkle root; those events are outranked by the 2026 publisher for every height it covers.

The local cache written by `hyperjump sync` stores legacy anchors rewritten to v3 shape (`C` = stop coordinate, `M` = merkle root) with a `cyberspace_cli_normalized` marker, so `nearest --cache` does not re-derive ~476k landfalls. Cache entries are not signed originals.

## Relay access

`wss://cyberspace.nostr1.com` requires NIP-42 AUTH for reads since 2026-08-23. `nak req` is now invoked with `--auth`; the local identity's key is passed via `NOSTR_SECRET_KEY` in the subprocess environment (never argv). An explicit `NOSTR_SECRET_KEY` in the caller's environment wins; without any key nak signs with its machine default.
